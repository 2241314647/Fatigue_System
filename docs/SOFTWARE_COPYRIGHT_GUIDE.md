本文档用于辅助整理 FatigueMon 的软件著作权申请材料。请以实际情况为准，如实填写作者、单位、完成日期、发表状态、权利取得方式和代码来源。

## 一、建议软件信息

- 软件全称：基于自适应范式与信号质量监控的脑电疲劳评估系统
- 软件简称：FatigueMon
- 版本号：V1.0
- 软件分类：数据采集与分析软件 / 科研实验辅助软件
- 开发语言：MATLAB
- 运行环境：Windows 10/11，MATLAB R2022b 或更高版本
- 依赖环境：Signal Processing Toolbox；真实设备模式下需要博瑞康脑电设备 SDK

## 二、功能简述

本软件面向脑电疲劳监测实验场景，提供被试信息管理、基线静息采集、PVT 持续注意任务、疲劳后再测、脑电预处理、行为指标分析、EEG 疲劳指标分析和综合疲劳评分等功能。系统支持真实脑电设备采集，也支持 Mock 模拟设备，用于无硬件环境下的教学、演示和流程验证。

## 三、技术特点

1. 支持基线、PVT、疲劳后再测的完整实验流程。
2. PVT 任务可根据近期反应时表现记录自适应刺激间隔变化。
3. 采集过程中可计算并记录信号质量提示信息。
4. 分析阶段融合行为反应时变异、EEG 频段功率和趋势斜率。
5. 内置 Mock 设备，便于开发调试和复现实验流程。
