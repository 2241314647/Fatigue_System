### 2.1 整体架构(3 大模块)

```
┌──────────────────────────────────────────┐

├──────────────────────────────────────────┤

│    - 基线静息任务                          │
│    - PVT 持续注意任务(含自适应难度)       │
│    - 疲劳后再测任务                        │
├──────────────────────────────────────────┤
│  ② 数据采集模块                            │
│    - 博瑞康设备实时通信                    │

├──────────────────────────────────────────┤
│  ③ 数据分析模块                            │
│    - PVT 行为分析                          │
│    - EEG 频段功率分析                      │

└──────────────────────────────────────────┘
```

### 2.2 主要功能列表(软著申请用)

#### A. 实验任务管理
1. 三任务工作流(基线 → PVT → 疲劳再测)
2. 任务参数可视化配置(齿轮对话框)
3. 实时状态监控与日志记录
4. 被试信息标准化管理

#### B. 数据采集
5. **自适应 PVT 范式**:根据被试反应稳定性动态调整刺激间隔(ISI),
   实现"反应慢→加大难度,反应稳→减压"的自适应实验流程
6. **实时信号质量监控**:在线计算 EEG 振幅、高频噪声、通道异常三项指标,
   屏幕角落以颜色提示被试,并将低质量时段自动标记到数据流
7. 博瑞康设备与 Mock 模拟设备无缝切换
8. 实时刺激展示(全屏黑底,经典 PVT 红色计时器样式)

#### C. 数据分析
9. PVT 行为分析(反应时分布、漏报率、d-prime 等)
10. EEG 频段功率谱分析(δ/θ/α/β)
11. 滑动窗口反应时变异系数(CV)分析
12. CV 趋势斜率早期预警
13. 个体化基线归一化(跨被试可比)
14. 综合疲劳评分(0-1,融合行为与 EEG)
15. 多维分析结果可视化(分析窗口)

#### D. 工程特性
16. 模块化分层设计(任务/工具/分析/测试 四层)
17. 完整 Mock 测试体系(无硬件环境可全流程运行)
18. 数据持久化(每次实验自动保存 .mat 文件)
19. 多被试管理(目录树结构)
20. 跨平台 MATLAB 兼容(R2022b+)

### 2.3 技术特点(申请表"软件功能简述")

> 本软件实现了一套面向疲劳监测应用的脑电采集与分析系统,主要技术特点包括:
> 
> 1. **自适应实验范式**:在标准 PVT 任务基础上,根据被试反应稳定性动态调整刺激间隔,既能更高效地诱发疲劳状态,又可减轻被试负担。
> 
> 2. **实时信号质量监控**:基于振幅、频域、通道一致性三类统计指标,实时评估采集质量,以颜色提示被试调整状态,并自动标记低质量时段供后续数据清洗参考。
> 
> 3. **多指标融合疲劳评估**:整合反应时变异性、EEG 频段比值、变化趋势斜率三类指标,输出 0-1 的综合疲劳评分,支持基线归一化以实现跨被试可比。
> 
> 4. **完整 Mock 测试体系**:内置模拟脑电设备,即使无真实硬件也能完成系统功能验证和教学演示,显著降低部署门槛。
> 
> 5. **模块化设计**:任务、采集、分析、测试四层解耦,便于扩展新任务和新指标。

## 三、创新点说明(诚实版)

### 3.1 与现有方法的差异

| 维度 | 常见疲劳监测系统 | 本系统 (FatigueMon V1.0) |
|------|------------------|--------------------------|
| 实验范式 | 固定 ISI 的 PVT | **自适应 ISI 的 PVT** |
| 信号质量 | 事后离线检查 | **采集时实时监控并提示** |
| 疲劳指标 | 单一指标(如反应时) | **多指标融合评分** |
| 跨被试对比 | 用绝对值 | **基线归一化**(更稳健) |
| 测试支持 | 需真实设备 | **Mock 设备 + 真实设备双轨** |

### 3.2 工程价值(不是算法发明,是系统整合)

本系统的价值定位为:

> **"将疲劳监测领域多年的研究成果,整合为一套即可用于临床/科研、又便于教学复现的工程系统。"**

每个单点功能在文献中都有先例,但**作为一个完整、可部署、可教学的系统**整合在一起,在国内开源工具中并不常见。这是本软件的工程价值所在,也是软著保护的对象。
